## Tải từ GitHub

Mở tệp `.pptx`, chọn **Download raw file** (biểu tượng tải xuống). GitHub có thể không hỗ trợ xem trước PowerPoint, nhưng vẫn cho tải tệp gốc. Có thể tải cả nhánh bằng **Code → Download ZIP**.

## Đưa lại vào Canva

1. Tải tệp PowerPoint lên Canva, rồi mở bản vừa nhập.
2. Trong chế độ Lưới, chọn trang 3–10 và sao chép.
3. Mở thiết kế gốc, chọn slide 9 rồi dán các trang mới phía sau.
4. Kiểm tra bố cục, sau đó xóa các slide 10–17 cũ bị trùng.

Chữ, hình vẽ và sơ đồ ở các trang hoàn thiện vẫn chỉnh sửa được.
